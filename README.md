# عدسة (Adasa) — React + Vite

## تشغيل المشروع
1. ثبّت Node.js (إصدار حديث).
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ `npm install` ثم `npm run dev`.
4. افتح الرابط الذي يظهر في الطرفية.

## Structure
- `src/main.jsx`: نقطة تشغيل React وRouter.
- `src/App.jsx`: جذر التطبيق.
- `src/routes/AppRoutes.jsx`: تعريف المسارات والتنقل.
- `src/pages/`: ملفات تصدير صفحات الموقع.
- `src/components/SiteComponents.jsx`: المكونات الأصلية وصفحات الموقع المستخرجة من الكود المرفق (محافظة على المنطق الأصلي).
- `src/data/posts.json`: بيانات المقالات والتصنيفات ومعلومات الموقع.
- `src/styles/global.css`: تنسيقات عامة أولية متوافقة مع أسماء الكلاسات في JSX.

> ملاحظة: ملف المصدر المرفق كان يحتوي على JSX مهروب بعلامات backslash، وتمت إعادته إلى JSX عادي. ملف CSS الأصلي لم يكن ضمن الملفات المرفقة، لذلك تم إنشاء stylesheet عام كبداية ويمكنك تطويره حسب التصميم الأصلي.
